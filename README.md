📋 **О проекте**

Это сайт, где выводятся на страницу новости. Данные берутся с клиента и с сервера

✨ **Основной функционал и что я сделала**

- Отобразила новости
- Сделала адаптивную и кроссбраузерную верстку. Сайт корректно отображается на телефонах и компьютерах, чьи экраны разных размеров.
  Верстка одинакова на основных браузерах: Хром, Яндекс, Edge, Opera, FireFox
- Показываю статус загрузки
- Показываю ошибку, если не получается извлечь данные с сервера.
  Указываю, что надо сделать, чтобы её исправить
- Сделала деплой проекта
- Стилизовала сайт

Свои нововведения:
- Если автор не указан в данных, то вывожу "Unknown author"
- Если нажать на кнопку Show more, то выходит весь текст статьи, полученной с сервера.
Её можно свернуть, если нажать на Show Less. Тогда можно увидеть снова фразы из статьи с ключевыми словами

🚀 **Как запустить проект**

**Предварительные требования**

npm/yarn

**Рекомендуемые расширения VS Code:**

ESLint

Prettier

ES7+ React/Redux/React-Native snippets

**Установка и запуск**

- Клонируйте репозиторий:

```
git clone https://github.com/RenataGaraeva/testTaskAPI.git
```

- Установите зависимости:

```
npm install
```

- Запустите проект:

```
npm run dev
```

- Откройте браузер и перейдите по адресу:\_\_
  http://localhost:5173/

**Скрипты**

```
"scripts":{
"dev": "vite",
"build": "vite build",
"lint": "eslint .",
"preview": "vite preview"
}
```
